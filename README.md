Available for 24/7 operations and on-call rotations.

**By the numbers**

- 10+ data center cabinets planned from scratch (power, cooling, cabling)

**What I've done**

- Configured **BGP, VLAN and LACP on Juniper** devices to optimize external routing and internal traffic isolation.

- Designed the backbone architecture for a VDS, dedicated server and web hosting platform and managed customer delivery.

- Migrated live **cPanel** servers to a new architecture with custom automation scripts, zero data loss and seamless DNS cutovers.
- Hardened **CloudLinux** servers with **Imunify360, ModSecurity WAF and CSF Firewall**.
- Automated repetitive configuration and backup tasks with **Bash and Ansible**.
